# AI Partner

ローカルで動作する、会話・心理状態・音声・ゲーム同伴を組み合わせたAIパートナーです。

公開版は **お嬢様キャラクター「エリシア」1人**に絞っています。ユーザー名や固定の呼称は設定しません。会話では名前を前提にせず、呼びかけ自体が不要なら二人称も省略して自然に返します。

## できること

- マイク入力から日本語で会話する
- 会話やプレイヤーの行動に応じて、信頼・好意・尊敬・反感などの心理状態を変化させる
- 一時的な怒り・喜び・悲しみ・興奮と、長期的な関係値を分けて管理する
- Irodori-TTSで感情を含む音声を生成する
- VNyanと連携して表情・口パクを動かす
- ゲーム中のシナリオやプレイヤー行動に反応する
- ゲームごとのシナリオファイルを **ローカルにだけ** 置いて読み込ませる
- 自作ゲームでは現在シーンやプレイヤー行動を状態ファイルから直接渡す
- 既存ゲームでは画面OCRとローカルシナリオの照合を利用できる

## セットアップ

現在は Windows / Python 3.11 を主対象にしています。

1. Python 3.11 と Ollama をインストールします。
2. リポジトリをダウンロードまたは clone します。
3. `setup.cmd` を実行します。
4. `run.cmd` を実行します。

`setup.cmd` は Python 仮想環境を作り、依存パッケージを入れ、Ollama の `qwen3.5:9b` と `qwen3.5:4b` を確認します。

初期設定では音声出力は `console` です。Irodori-TTS を使う場合は、`config.user.example.yaml` を `config.user.yaml` にコピーし、手元の Irodori-TTS のパスと必要なら参照音声を設定してください。`config.user.yaml` は Git 管理対象外です。

VNyan は任意です。使う場合だけ `config.user.yaml` で有効にしてください。

## 会話履歴のリセット

会話履歴だけを消し、心理状態やゲームイベントを残す場合は次を実行します。

```bat
.venv\Scripts\python.exe run_partner.py --reset-conversation
```

## ゲームデータ

このリポジトリには、特定ゲームのシナリオ、抽出データ、タイトル専用コードを含めません。

各自のゲームデータは `local_games/` 以下に置きます。このフォルダは Git 管理対象外です。

```text
local_games/
  my_game/
    game.yaml
    scenario/
      scenario.csv
    runtime_state.json   # 自作ゲームなどで任意
```

AIへ渡すのは原則として **現在までに到達した情報だけ** です。シナリオ全体を会話コンテキストへそのまま渡す設計にはしていません。

### 自作ゲーム

`runtime_state.json` をゲーム側から更新すると、現在のシーン、表示中の台詞、選択肢やプレイヤー行動を直接通知できます。画面認識に頼らないため、シナリオを持っているゲームではこの方法が最も正確です。

### 既存ゲーム

`tracking.method: screen_ocr` を指定すると、Windows OCRで表示文字を読み、ユーザーがローカルに置いたシナリオと曖昧照合できます。また `gameplay_rules` に「勝利」「敗北」「戦闘不能」などの文字パターンを定義し、プレイヤーの出来事として心理状態へ反映できます。

詳しくは [GAME_PACKS.md](GAME_PACKS.md) と `examples/game_pack/` を参照してください。

## 心理状態について

長期的な関係値と、その瞬間の感情は別に扱います。

たとえば高い `arousal` / 興奮状態は会話の勢いやテンポには影響しますが、軽い怒りを激怒へ自動的に増幅しません。その一言の感情と強さは、現在の発話や出来事から別に判断します。

ゲーム内の登場人物の行動と、プレイヤー自身の行動も分離します。原則として、長期的な信頼・好意・尊敬・反感を動かすのは `actor_scope: user` のプレイヤーイベントです。

## 動作確認環境

作者環境では以下で動作確認しています。

- Windows
- NVIDIA GeForce RTX 4070
- VRAM 12 GB
- RAM 64 GB
- Python 3.11
- Ollama
- Irodori-TTS

これは **動作確認済み環境** であり、最低動作要件ではありません。GPUやメモリが少ない環境では、使用モデル、コンテキスト長、GPUレイヤー数、Whisperの設定などの調整が必要になる可能性があります。

## キャラクター

公開版ではエリシアのみを収録しています。キャラクター選択画面、新規キャラクター作成機能、固定ユーザー名の設定はありません。

## 公開版の方針

- 個人の会話履歴・心理状態・音声素材を含めない
- 特定ゲームの著作物やシナリオを含めない
- ゲーム固有データはローカルの Game Pack として分離する
- ローカル中心で動作させる
- 自発発話には過去の会話履歴を渡さず、沈黙中に昔の話題を勝手に再開しない

## 開発状況

公開版は実行可能な初期版です。現在も個人用の実動作版で得た改善を、タイトル固有情報を含まない形で整理して反映しています。
