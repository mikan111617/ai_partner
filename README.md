# AI Partner

ローカルで動作する、会話・心理状態・音声・ゲーム同伴を組み合わせたAIパートナーです。

現在の公開版は、**お嬢様キャラクター1人**に絞っています。ユーザー名や固定の呼称は必要ありません。会話では特定の名前を前提にせず、自然に相手へ話しかけます。

## できること

- マイク入力から会話する
- 会話や出来事に応じて心理状態を変化させる
- Irodori-TTSで感情を含む音声を生成する
- VNyanと連携して表情・口パクを動かす
- ゲーム中の会話や出来事に反応する
- ゲームごとのシナリオファイルを**ローカルにだけ**置いて読み込ませる
- 自作ゲームでは現在シーンやプレイヤー行動を状態ファイルから直接渡す
- 市販ゲームなどでは、画面OCRとローカルシナリオの照合を利用できる

## ゲームデータについて

このリポジトリには、特定ゲームのシナリオ、抽出データ、専用コードは含めません。

各自のゲームデータは `local_games/` 以下に置く設計です。このフォルダはGit管理対象外です。

```text
local_games/
  my_game/
    game.yaml
    scenario/
      scenario.csv
    runtime_state.json   # 自作ゲームなどで任意
```

AIへ渡すのは原則として**現在までに到達した情報だけ**です。シナリオ全体をモデルの会話コンテキストへそのまま渡す設計にはしません。

## 動作確認環境

作者環境では以下で動作確認しています。

- Windows
- NVIDIA GeForce RTX 4070
- VRAM 12 GB
- RAM 64 GB
- Python 3.11
- Ollama
- Irodori-TTS

これは**動作確認済み環境**であり、現時点では最低動作要件を保証するものではありません。GPUやメモリが少ない環境では、使用モデルやGPUレイヤー数などの調整が必要になる可能性があります。

## キャラクター

公開版では「お嬢様」のみを収録します。キャラクター選択画面や固定ユーザー名の設定はありません。

## 公開版の方針

- 個人の会話履歴・心理状態・音声素材を含めない
- 特定ゲームの著作物やシナリオを含めない
- ゲーム固有部分はローカルのGame Packとして分離する
- ローカル中心で動作させる
