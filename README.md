# AI Partner

AI Partner は、ローカル環境で動作する日本語向けのAIコンパニオンです。

マイクで会話しながら、長期的な関係値と一時的な感情を別々に管理し、必要に応じて Irodori-TTS や VNyan と連携できます。公開版のキャラクターは、お嬢様キャラクター「エリシア」1人です。

ユーザー名や固定の呼称は必要ありません。会話では特定の名前を前提にせず、呼びかけが不要な場面では二人称も省略します。

## 主な機能

- マイク入力から日本語で会話
- 信頼・好意・尊敬・反感などの長期的な関係値を保持
- 喜び・怒り・悲しみ・興奮などの一時的な感情を別レイヤーで管理
- Irodori-TTS による感情付き音声出力
- VNyan と連携した表情・口パク
- ゲーム画面に表示された勝敗や戦闘不能などの出来事への反応
- 自作ゲームや連携を許可されたゲームから、現在の出来事を状態ファイル経由で通知
- 会話履歴と心理状態のローカル保存

## 対象環境

現在は Windows / Python 3.11 を主対象にしています。

### 動作確認環境

以下の環境で動作確認しています。

- Windows
- NVIDIA GeForce RTX 4070
- VRAM 12 GB
- RAM 64 GB
- Python 3.11
- Ollama
- Irodori-TTS

これは最低動作要件ではありません。GPUやメモリが少ない環境では、使用モデル、コンテキスト長、GPUレイヤー数、Whisperの設定などの調整が必要になる場合があります。

## セットアップ

1. Python 3.11 と Ollama をインストールします。
2. このリポジトリをダウンロードまたは clone します。
3. `setup.cmd` を実行します。
4. `run.cmd` を実行します。

`setup.cmd` は Python 仮想環境を作成し、必要な依存パッケージをインストールします。

初期設定では音声出力は `console` です。

Irodori-TTS を使用する場合は、`config.user.example.yaml` を `config.user.yaml` にコピーし、Irodori-TTS のパスと必要に応じて参照音声を設定してください。`config.user.yaml` は Git 管理対象外です。

VNyan は任意です。使用する場合のみ `config.user.yaml` で有効にしてください。

## ゲーム連携

AI Partner は、ゲームデータそのものを配布・取得する仕組みではありません。

公開版では、既存ゲームのシナリオファイルや抽出データを読み込ませる方法は提供していません。

### 既存ゲーム

正規に入手・利用しているゲームでは、画面に実際に表示された文字を Windows OCR で読み取り、`gameplay_rules` に設定した「勝利」「敗北」「戦闘不能」などのパターンを検出できます。

この方法はゲームファイルやシナリオデータを取り込まず、現在画面に表示されている情報だけを対象にします。

### 自作ゲーム・許諾済みゲーム

ゲーム側から `runtime_state.json` を更新できる場合は、現在の出来事やプレイヤー行動を AI Partner へ直接通知できます。

これにより、たとえば次のような情報を心理状態へ反映できます。

- 危険な選択をした
- 戦闘に勝利した
- 敗北した
- 仲間を助けた
- 大胆な行動を取った

詳しい設定方法は [GAME_PACKS.md](GAME_PACKS.md) を参照してください。

## ゲーム利用について

このプロジェクトは、ゲームや関連データの不正入手・無断配布・アクセス制限の回避を目的としていません。

利用するゲーム、データ、素材については、正規に入手し、利用権限のあるものを使用してください。また、各ゲーム、配信プラットフォーム、サービスの利用規約や権利者の条件に従ってください。

このリポジトリには、特定ゲームのシナリオ、抽出データ、ゲーム本体、タイトル専用の著作物は含めません。

## 心理状態

長期的な関係値と、その瞬間の感情は別に扱います。

たとえば高い `arousal` / 興奮状態は会話の勢いやテンポには影響しますが、軽い怒りを自動的に激怒へ増幅しません。その発話の感情と強さは、現在の会話や出来事から別に判断します。

ゲーム内の登場人物の行動と、プレイヤー自身の行動も区別します。原則として、長期的な信頼・好意・尊敬・反感を変化させるのは、プレイヤー自身の行動として明示されたイベントです。

## 会話履歴のリセット

会話履歴だけを削除し、心理状態やゲームイベントを残す場合は次を実行します。

```bat
.venv\Scripts\python.exe run_partner.py --reset-conversation
```

## キャラクター

公開版ではエリシアのみを収録しています。

キャラクター選択画面、新規キャラクター作成機能、固定ユーザー名の設定はありません。

## プライバシーとローカルデータ

次のデータは Git 管理対象外です。

- 会話履歴
- 心理状態
- 個人用設定
- 参照音声
- ローカルのゲーム連携設定

公開リポジトリには個人の実行データを含めない方針です。
