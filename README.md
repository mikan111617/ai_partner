# AI Partner

AI Partner は、ローカル環境で動作する日本語向けのAIコンパニオンです。

マイクで会話しながら、信頼・好意・尊敬・反感などの長期的な関係値と、その瞬間の感情を別々に管理します。公開版のキャラクターは、お嬢様キャラクター「エリシア」1人です。

ユーザー名や固定の呼称は必要ありません。

## 主な機能

- マイク入力から日本語で会話
- 信頼・好意・尊敬・反感などの長期的な関係値を保持
- 喜び・怒り・悲しみ・興奮などの一時的な感情を別レイヤーで管理
- Irodori-TTS による感情付き音声出力
- VNyan と連携した表情・口パク
- ゲーム画面に表示された文字から、勝利・敗北・戦闘不能などの出来事を検出して反応
- ゲーム側から現在の出来事やプレイヤー行動を直接通知する連携
- 会話履歴と心理状態のローカル保存

## 必要なもの

AI Partner の公開版は、次の構成を前提にしています。

- Windows
- Python 3.11
- Ollama
- Irodori-TTS
- マイク

Irodori-TTS は必須です。AI Partner の音声出力は Irodori-TTS を前提にしています。

VNyan は任意です。3Dキャラクターの表情や口パクを動かしたい場合に使用します。

## 動作確認環境

以下の環境で動作確認しています。

- Windows
- NVIDIA GeForce RTX 4070
- VRAM 12 GB
- RAM 64 GB
- Python 3.11
- Ollama
- Irodori-TTS

これは最低動作要件ではありません。GPUやメモリが少ない環境では、動作速度や使用できるモデルに差が出る可能性があります。

## セットアップ

### 1. Python 3.11 をインストール

Python 3.11 をインストールしてください。

### 2. Ollama をインストール

Ollama をインストールしてください。

`setup.cmd` を実行すると、AI Partner で使用する `qwen3.5:9b` と `qwen3.5:4b` を確認し、無ければ取得します。

### 3. Irodori-TTS を用意

Irodori-TTS をインストールし、単体で音声生成できる状態までセットアップしてください。

標準設定では、Irodori-TTS が次の場所にある前提です。

```text
D:\Irodori-TTS
```

別の場所に置く場合は、`config.user.example.yaml` を `config.user.yaml` にコピーし、`irodori_dir` を実際の場所へ変更してください。

参照音声を使う場合は、同じファイル内の `irodori_reference_audio` に WAV ファイルの場所を指定します。

### 4. AI Partner をセットアップ

このリポジトリをダウンロードまたは clone し、`setup.cmd` を実行してください。

Python の仮想環境と必要なライブラリが用意されます。

### 5. 起動

`run.cmd` を実行します。

初回は Whisper や Irodori-TTS のモデル読み込みに時間がかかる場合があります。

## ゲーム中の反応

ゲーム画面に表示された文字を Windows OCR で読み取り、`gameplay_rules` に設定した文字パターンから出来事を検出できます。

たとえば「勝利」「敗北」「戦闘不能」などを検出し、お嬢様の感情やプレイヤーへの評価へ反映できます。

また、ゲーム側から `runtime_state.json` を更新できる場合は、現在の出来事やプレイヤー行動を AI Partner へ直接通知できます。

詳しい設定方法は [GAME_PACKS.md](GAME_PACKS.md) を参照してください。

## 心理状態

長期的な関係値と、その瞬間の感情は別に扱います。

たとえば高い `arousal` / 興奮状態は会話の勢いやテンポには影響しますが、軽い怒りを自動的に激怒へ増幅しません。その発話の感情と強さは、現在の会話や出来事から別に判断します。

ゲーム中の出来事についても、敗北しただけで信頼が大きく下がるような単純な処理にはしていません。出来事の種類に応じて、尊敬・心配・興奮などが別々に変化します。

## 会話履歴のリセット

会話履歴だけを削除し、心理状態やゲームイベントを残す場合は次を実行します。

```bat
.venv\Scripts\python.exe run_partner.py --reset-conversation
```

## キャラクター

公開版ではエリシアのみを収録しています。

キャラクター選択画面、新規キャラクター作成機能、固定ユーザー名の設定はありません。

## ローカルに保存されるデータ

会話履歴、心理状態、個人用設定、参照音声、ゲーム連携設定はローカルで使用します。

`config.user.yaml`、`data/`、`local_games/` などは Git 管理対象外です。
